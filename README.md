# Canuckle Archive — Past 5-Letter Word Recap & PDF Tool

A lightweight open-source reference database and static tool indexing past 5-letter solutions from the Canadian word puzzle game **Canuckle**. This repository hosts the frontend codebase for browsing historical recaps and downloading printable monthly word lists in PDF format.

## 🔗 Live Application

Access the full searchable database, daily recaps, and instant PDF downloads:

👉 **[Open Canuckle Archive Web App](https://canucklegames.com/canuckle-archive/)** 

---

## 📌 Project Overview

This utility serves word puzzle enthusiasts, vocabulary researchers, and trivia fans by organizing verified historical solutions with Canadian cultural context.

* **Two-Month Solution Archive:** Chronological list of verified 5-letter game answers.
* **1-Click PDF Export:** Download structured monthly word sheets for offline study and reference.
* **Zero Dependencies:** Pure HTML5, modern CSS, and Vanilla JavaScript with fast loading speeds.
* **Semantic Structure:** Optimized with clean markup, accessible tables, and mobile-first responsiveness.
